About

What this is
Sourcebook is a directory of legacy iOS repos, with a filter for iOS version, search, and sorting. It is a personal project, and this is an early version.
What it does not do
It does not host, check, or verify any tweak or package. Each listed repo is run by its owner. Install only from sources you trust.
Using the list
Tap a repo to see its tweaks, when it was last checked, and a report link. Tap a tweak to open its details. Use the search box to find a repo or tweak by name, and the sort menu to order the list.
Tap Save to keep a repo in your list. Saved repos are stored on your device only, and nothing is sent anywhere.
Recently changed
Repos that their owners updated in the last 7 days appear at the top of the list.
Status dots
Green: the repo responded in the last day. Orange: no response for 3 days. Red: no response for 7 days. Grey: never checked. The status is refreshed by a scheduled job every few hours, so it may lag behind.
Add to Cydia
Some repos have an Add to Cydia button. It asks your package manager to add that repo as a source. It does not install anything. Only repos whose owners have opted in show this button.
Get your repo listed
Listing is opt-in only. Use "Add your repo" on the home page, and the owner must agree. You can ask to be removed at any time through "Report a problem" on your repo's row.
