About

What this is
Sourcebook is a directory of legacy iOS repos, with a filter for iOS version, a search box, and a status dot for each repo. It is a student project, and this is an early version.
What it does not do
It does not host, check, or verify any tweak or package. Each listed repo is run by its owner. Install only from sources you trust.
Status dots
Green: the repo responded in the last day. Orange: no response for 3 days. Red: no response for 7 days. Grey: never checked. The status is refreshed by a scheduled job, so it may lag behind.
Get your repo listed
Listing is opt-in only. Use "Add your repo" on the home page, and the owner must agree. You can ask to be removed at any time through "Report a problem" on your repo's row.
